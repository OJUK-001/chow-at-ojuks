CHOW@OJUKS — NIGERIAN RESTAURANT WEBSITE

FILES
index.html = Home page
about.html = About page / restaurant story
menu.html = Services / Nigerian delicacies menu
contact.html = Contact page, opening hours and drop-a-message form
css/style.css = Styling, CSS Grid and responsive layouts
js/main.js = Mobile navigation and WhatsApp form interaction

OPEN IN VS CODE
1. Extract the ZIP file.
2. Open VS Code > File > Open Folder.
3. Select the extracted CHOW_AT_OJUKS folder.
4. Open index.html and right-click > Open with Live Server (if installed).
5. You can also double-click index.html to open it in your browser.

EDIT THESE DETAILS BEFORE SUBMISSION
- WhatsApp contact number is set to 0703 404 9493 in js/main.js.
- Lagos, Nigeria is a sample location; add the real restaurant address.
- Opening hours are sample hours; update them if needed.
- Menu prices are placeholders (₦ ———); add your preferred prices.
- Food photos show Nigerian dishes and load from online image sources, so internet access is required.

DESIGN PALETTE: pepper red, warm cream, charcoal, leaf green and suya gold.
TECH: HTML, CSS, CSS Grid, responsive media queries and JavaScript.
